# ThinkBlank project guidance

Use `.agents/skills/super-web-design/SKILL.md` for all website design, implementation, and review work in this project, unless the user overrides it. The user wants this skill applied throughout the project without needing to invoke it each time.

Preserve the GitHub-to-Cloudflare Pages workflow. The buildless website lives in `dist/`; no build command is required. Distinguish source uploads from verified deployments.

Use ThinkBlank as the portfolio brand. Keep unsupplied photographs, biography, and contact details clearly marked as placeholders. Never present stock photography as the user's work.
